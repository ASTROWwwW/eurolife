# EuroLife

Archive of a FiveM roleplay server base, built on ESX. It is no longer maintained.

## Contents

Everything lives in `resources/`, grouped by folder:

- `[ESX]` and `[ESX ADDONS]`: the framework and its add-ons
- `[EuroLife]`: the server's own resources (activities, admin tools, robberies)
- `[STANDALONE]`: standalone libraries such as oxmysql
- `[VOICE]`: voice chat and phone resources
- `[FIVEM DEFAULT]`: default FiveM resources

## Notes

- No support and no updates.
- Third-party resources keep their own authors and licenses.
- Set your own database, webhooks and keys before running anything.
